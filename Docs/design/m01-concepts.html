Fernverkehr

The name taken literally: fernjo as the long-distance timetable of your machines

The connection tree reads like a timetable: every connection is a line with its category code (SSH, RDP) and its host in a fixed column, set in a semi-condensed grotesque with tabular figures. The sidebar is the platform display, deep blue with white type; the session area stays calm and light. Inheritance uses the timetable's own device: footnote marks.

Signature move
Inherited values carry a footnote letter; the legend under the properties names the folder (a = from Work). No mark means "set here".
Type
Archivo semi-condensed (UI), Source Code Pro (terminal)
Density
22 px rows, host column always visible
Colour
Committed: blue shell, white work area; red only where something needs attention
Differs from the others in
coloured shell, condensed type, host column, footnote inheritance
Honest risk
The big blue sidebar is a strong colour to look at all day; the condensed face needs good hinting at 125 % scaling on Windows.
Disciplines borrowed from directions that were weighed and declined
  • From the spectrogram plate: session state is carried by mark form (filled = live, hollow = connecting, struck = dropped), never by hue alone.
  • From the pocket airline timetable: rank by weight and reversal at two sizes; the selected row is the one reversed plate on the screen.
  • From the reference-edition page: every rule is one pixel, and the palette stays at three values plus one signal colour.
  • From the convention catalog: density courage, with codes and hosts packed into a 22 px line.
  • From the Metro tiles: no decorative borders; areas are separated by ground colour.

Ulm, revised

Round 1 with your feedback; the original Ulm stays in the switcher for comparison
  • Lamps only where something runs: no session = no lamp, connecting = pulsing ring, live = filled, dropped = struck. State is told by shape; colour only supports it.
  • Selection is a darker row with a bar on the left and semibold text; keyboard focus is a 1 px outline.
  • A locked vault is not modal: a note at the top of the sidebar, the tree stays usable, and the password is asked inside the tab of the connection that needs it (views "Unlock" and "Unlock error").
  • Host column as an option (switch above): greyed address on the right, the lamp in the last column.
  • The properties panel collapses (click its header or use the switch above), so the whole tree fits.
  • Property labels in normal case, 12 px, grey.
  • Reconnect is yellow on every dropped tab (pve-01, backup-nas), so dropped sessions stand out in the tab bar. Everywhere else yellow stays reserved for the one action that matters (Unlock and connect).
  • Terminal minimum contrast 4.5 : 1, on by default (xterm.js minimumContrastRatio): the palette stays, foreground colours that are too faint are darkened or lightened when drawn. Here: ANSI white on light, ANSI black and bright black on dark, and three colours just under 4.5.
Type
Hanken Grotesk (UI), Red Hat Mono (terminal)
Density
24 px rows
Colour
Warm neutrals, yellow as the only accent, green/amber/red only in lamps and marks

Ulm

Braun and the Ulm school of design: a well-made instrument that stays quiet

Warm grey housing, off-white working surfaces, charcoal type and exactly one yellow key: the action that matters right now (Reconnect, Unlock), like the equals key on a Braun calculator. Session state lives in a column of small indicator lamps at the right edge of the tree.

Signature move
Indicator lamps (lit = live, ring = connecting, struck = dropped) in one fixed column; a single yellow key per screen.
Type
Hanken Grotesk (UI), Red Hat Mono (terminal); small uppercase labels in the properties
Density
24 px rows, the calmest of the four
Colour
Restrained: warm neutrals, yellow as the only accent, green/amber/red only in lamps
Differs from the others in
warm neutral palette, lamp column, single-key accent, roomier rows
Honest risk
Familiar: this is the most conventional of the three own directions and could slide toward the quiet grey tool if executed without precision.

Gate

The airport sign system: you always know where you are and where you are going

Black and white with yellow reserved for one job: showing where you are. The selected connection and the active tab are yellow; above the properties, a yellow sign band shows the path to the selection in large type. Protocols are white pictograms on black squares, readable from across the room.

Signature move
The "you are here" sign band: folder path and connection name at sign scale, in the same yellow as the active tab.
Type
Fira Sans (UI, humanist like airport signage), Fira Code (terminal)
Density
24 px rows
Colour
Committed: black tab strip, yellow strictly for position, state colours only in marks
Differs from the others in
black tab strip, pictogram squares, sign band, highest contrast
Honest risk
Yellow in a dark theme is bright over long sessions; its world is close to Fernverkehr's (both are travel signage).

Workbench

The category standard, played straight

What a careful team would ship in this category today: neutral greys, one blue accent, the system UI font and a familiar IDE-like structure. No world of its own; included so the familiar option is a real choice.

Type
System UI font (Segoe UI, SF Pro, Cantarell per OS), JetBrains Mono (terminal)
Density
22 px rows
Colour
Restrained: grey neutrals and one blue
Honest risk
Reads like many other tools; fernjo would have no look of its own.
Also weighed and declined (their disciplines went into Fernverkehr above):
  • Spectrogram working plate: dark charcoal with hairline colour; too close to the hacker look you ruled out.
  • Pocket airline timetable on a light table: one type size and raked slides; the rake fights a working tree.
  • Wide-margin reference edition: bone paper and vermilion keys; a reading world, not an operating one.
  • Convention circle catalog: newsprint thumbnail grid; no fit for a connection tree.
  • Metro tiles: giant cropped lowercase; wastes the space the tree and terminal need.

All names, hosts and addresses are synthetic (example names, IP ranges reserved for documentation). The native window title bar is not drawn. Fonts load from Google Fonts here only; the app will bundle its fonts.
